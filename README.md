# 💬 Online Chat Application

A full-stack, real-time messaging platform featuring private chats, user presence tracking, and profile management. This project demonstrates a robust implementation of WebSockets for instant communication and a modern React-based user interface.

------

## ✨ Features

- **Real-Time Messaging:** Instant message delivery using WebSockets.
- **User Presence:** Real-time status tracking (Online/Offline) and "Last Seen" timestamps.
- **Private Conversations:** Dedicated chat history between users, persisted in SQLite.
- **Profile Management:** Custom Bio and Birthdate updates. Profile picture uploads and storage.
- **User Search:** Find other users via a dynamic search bar.
- **Secure Authentication:** JWT-based login and registration system with password hashing.

------

## 🛠️ Tech Stack

### Backend

- **Framework:** FastAPI (Python)
- **Database:** SQLite
- **Communication:** WebSockets for real-time bi-directional data.
- **Security:** Password hashing and JWT access tokens.
- **File Handling:** Static file mounting for profile image uploads.

### Frontend

- **Framework:** React with TypeScript
- **UI Library:** Material UI (MUI)
- **Routing:** React Router DOM
- **State Management:** Context API (Auth) and custom hooks for WebSocket logic.
